# An Introduction to Seismology

An educational web platform about the science of seismology, earthquakes, and seismic data analysis.

The website combines written articles with interactive tools, allowing users not only to read about earthquake-related phenomena but also to explore real seismological data through hands-on visualizations.

## Features

- Educational articles about seismology and earthquake-related topics
- Interactive seismic tools built with React
- Real seismological data served through a FastAPI backend
- Responsive UI styled with Tailwind CSS
- Modern static site structure using Astro
- Clear separation between content pages and interactive applications

## Tech Stack

### Frontend
- Astro
- React
- Tailwind CSS

### Backend
- FastAPI
- Python

## Project Structure

The website contains two main types of pages:

### Articles
Educational pages where users can learn about seismology concepts, earthquake phenomena, and seismic data interpretation.

### Interactive Tools
React-based tools that allow users to interact with seismic data and better understand seismological concepts through practical examples.

## Purpose

This project was built to make seismology more accessible by combining scientific explanations with interactive web-based tools.

It also demonstrates full-stack development skills, including frontend development, backend API design, data handling, and scientific visualization.
